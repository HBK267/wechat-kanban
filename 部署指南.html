测绘一部管理看板 · 公网部署指南

把看板部署到免费云平台 Render，获得微信用户可直接点击的 HTTPS 链接

重要提醒：Render 免费版实例在 15 分钟无访问后会休眠，休眠/重启后新增的数据可能丢失。若数据重要，建议部署稳定后升级到付费版（约 $7/月，含持久化磁盘）。本指南先帮你把免费版跑通。

① 准备账号（约 5 分钟）

1

注册一个 GitHub 账号：github.com（已有可跳过）

2

注册一个 Render 账号：render.com，注册时选择"Sign in with GitHub"直接绑定 GitHub

② 把项目代码推送到 GitHub

1

在 GitHub 新建一个仓库（写 wechat-kanban，Public 公开，不要勾选自动生成 README）

2

在项目目录执行以下命令，把代码推送到你的仓库（把 你的用户名 换成你的 GitHub 用户名）：

git branch -M main git remote add origin https://github.com/你的用户名/wechat-kanban.git git push -u origin main

③ 在 Render 一键部署（约 3 分钟）

1

登录 Render，点击 New → Blueprint（项目已内置 render.yaml，会自动识别）

2

连接你的 GitHub 仓库 wechat-kanban，Render 会自动读取配置并开始构建

3

等待 1~3 分钟构建完成，页面会显示服务地址，形如：

https://wechat-kanban.onrender.com

④ 发到微信使用

1

用浏览器打开部署后的链接，确认能正常显示看板

2

复制该链接，发送到微信好友或群聊

3

微信用户点击链接即可进入看板，填写、编辑、同步所有信息

提示：首次打开如果较慢，是因为免费实例正在从休眠中唤醒，属正常现象。
本看板无登录认证，任何拿到链接的人都能编辑，请仅分享给协作成员。
